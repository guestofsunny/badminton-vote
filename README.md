# 约球投票 · 未来 7 天

一个用于微信群分享的单页投票网页：自动生成未来 7 个自然日（含日期和星期），所有人可报名、替人报名、编辑投票人，搜索并选择打球地点。

## 功能

- 自动以当天为第一天生成未来 7 天投票卡片，跨天自动刷新
- 头像昵称自动读取登录信息（链接参数 `?name=...&avatar=...`，或宿主注入的用户变量）；读不到时用昵称首字
- 点卡片为自己报名，点名字移除任意投票人，「替人报名」可为他人报名
- 腾讯地图（GL JS，合规代理模式）搜索选点 + 逆地理编码；默认定位北京；地图服务不可用时用内置北京常用球馆离线列表
- 本机模式：数据存储在本机浏览器 localStorage，页面底部可复制 / 导入数据手动合并

## 部署

这是一个纯静态页面，把 `index.html` 放到任意静态托管即可，例如 GitHub Pages：

1. 在 GitHub 创建一个仓库（例如 `badminton-vote`）
2. 上传 `index.html`（和本 README）
3. 仓库 Settings → Pages → Source 选择 `main` 分支 / `root` 目录
4. 打开生成的 Pages 链接即可分享

## 注意

- 地图依赖 WorkBuddy 运行时的本地代理占位符（`__WB_HTTP_PORT__`、`__WB_TMAP_SECRET__`），在纯 GitHub Pages 上代理不可用，地图可能无法显示；此时可用页面里的「热门搜索」离线结果和「手动输入坐标」保存地点。
- 微信群场景如需所有人实时看到同一份结果，需要接入共享后端（微信授权登录 + 云数据库），当前版本是本机模式。
